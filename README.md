# MM-Lab: ห้องทดลองมัลติมีเดียเชิงโต้ตอบ (Interactive Multimedia Laboratory)

สื่อการเรียนรู้ดิจิทัลเชิงโต้ตอบแบบ Single Page Application (SPA) สำหรับนักศึกษาครูคอมพิวเตอร์ เพื่อศึกษาและทดลองปรับแต่งคุณลักษณะทางเทคนิคขององค์ประกอบมัลติมีเดีย (ข้อความ ภาพ เสียง และวิดีโอ) ผ่านการจำลองผลลัพธ์แบบเรียลไทม์ พร้อมระบบตรวจภารกิจและแบบทดสอบประเมินผลสัมฤทธิ์

---

## 🎯 วัตถุประสงค์การเรียนรู้
1. **ข้อความและสี:** อธิบายและคำนวณอัตราส่วนความต่างสี (Contrast Ratio) ตามเกณฑ์มาตรฐาน WCAG 2.1 ได้
2. **ภาพดิจิทัล:** อธิบายความสัมพันธ์ระหว่างความละเอียด (Resolution), ความลึกบิต (Bit Depth) และขนาดข้อมูลภาพดิบได้
3. **เสียงดิจิทัล:** อธิบายหลักการสุ่มตัวอย่าง (Sampling Rate), การแปลงระดับขั้น (Quantization) และเงื่อนไข Nyquist-Shannon Sampling Theorem ได้
4. **วิดีโอดิจิทัล:** อธิบายผลของอัตราเฟรม (Frame Rate) และอัตราการบีบอัดข้อมูล (Compression Ratio) ต่อบิตเรตและขนาดไฟล์ได้

---

## 🧪 โครงสร้างสถานีการเรียนรู้ (5 สถานี)

### 1. สถานีข้อความและสี (Text & Color Contrast)
* **การทำงาน:** ตัวปรับแต่งสี Foreground/Background, ขนาดตัวอักษร (12–40 px) และสไตล์ตัวหนา
* **ทฤษฎีเบื้องหลัง:** คำนวณความสว่างสัมพัทธ์ (Relative Luminance) เชิงเส้น:
  $$L = 0.2126R + 0.7152G + 0.0722B$$
  และอัตราส่วนความต่างสี:
  $$\text{Contrast Ratio} = \frac{L_{\text{lighter}} + 0.05}{L_{\text{darker}} + 0.05}$$
* **เกณฑ์ประเมิน:** ตรวจสอบความสอดคล้องตามมาตรฐาน WCAG 2.1 ระดับ AA (ข้อความปกติ $\ge 4.5:1$, ข้อความใหญ่ $\ge 3.0:1$) และ AAA ($\ge 7.0:1$)

### 2. สถานีภาพดิจิทัล (Digital Image & Color Depth)
* **การทำงาน:** ปรับลดสเกลความละเอียดแบบ Pixelated (3%–100%) และลดระดับความลึกบิตต่อช่องสี (1–8 bpc) พร้อมตัวผสมแม่สี RGB เชิงโต้ตอบ
* **การคำนวณขนาดข้อมูลดิบ:**
  $$\text{Raw Bytes} = \frac{\text{Width} \times \text{Height} \times \text{Bit Depth} \times 3}{8}$$

### 3. สถานีเสียงดิจิทัล (Digital Audio & Sampling)
* **การทำงาน:** วาดกราฟคลื่นไซน์ 440 Hz จำลองจุดสุ่มตัวอย่างและเส้นคลื่นขั้นบันได (Quantized Wave) พร้อมระบบสังเคราะห์เสียงจริงผ่าน Web Audio API
* **ทฤษฎีเบื้องหลัง:** ตรวจสอบเกณฑ์ Nyquist Rate ($f_s > 2 \times f_{\text{signal}}$) และคำนวณอัตราการถ่ายโอนข้อมูลเสียงโมโนดิบ:
  $$\text{Data Rate (Bytes/s)} = \frac{\text{Sampling Rate} \times \text{Bit Depth}}{8}$$

### 4. สถานีวิดีโอและการบีบอัด (Video & Compression)
* **การทำงาน:** จำลองการเคลื่อนไหวตามอัตราเฟรมจริง (2–60 fps) เพื่อสังเกตความลื่นไหล พร้อมแถบจำลองอัตราส่วนบีบอัดแบบ Logarithmic Scale (1:1 ถึง 300:1)
* **การคำนวณ:** คำนวณบิตเรตดิบ (Uncompressed Bitrate) และขนาดไฟล์วิดีโอความยาว 1 นาที

### 5. สถานีภารกิจสรุปผล (Comprehensive Assessment)
* แบบทดสอบสถานการณ์จำลอง 5 ข้อ พร้อมระบบเฉลยและอธิบายเหตุผลทันที เพื่อปลดล็อกตราสัญลักษณ์ความสำเร็จครบทุกสถานี

## 💻 ข้อกำหนดและคุณสมบัติทางเทคนิค
* **โครงสร้าง:** Single HTML File (`index.html`) รวม CSS และ JavaScript ภายในไฟล์เดียว
* **การแสดงผล:** รองรับ Responsive Web Design (ขนาดหน้าจอตั้งแต่ 390 px ถึงหน้าจอเดสก์ท็อป)
* **ระบบธีม:** รองรับ Light Mode และ Dark Mode ผ่าน CSS Custom Properties และ `prefers-color-scheme`
* **การจัดเก็บข้อมูล:** บันทึกสถานะตราสัญลักษณ์ภารกิจลงใน `localStorage` โดยไม่มีการจัดเก็บข้อมูลส่วนบุคคล
* **การเข้าถึง (Accessibility):** รองรับการนำทางด้วยคีย์บอร์ด, Focus Ring ชัดเจน และเคารพการตั้งค่า `prefers-reduced-motion`

## 🚀 วิธีการติดตั้งและเปิดใช้งาน

1. **เปิดผ่านเบราว์เซอร์โดยตรง (Local):**
   * ดาวน์โหลดไฟล์ `index.html`
   * ดับเบิลคลิกเปิดไฟล์ด้วย Google Chrome, Microsoft Edge, Mozilla Firefox หรือ Safari

2. **เปิดผ่าน GitHub Pages (Online):**
   * ไปที่แท็บ **Settings** ของ Repository
   * เลือกเมนู **Pages** ทางด้านซ้าย
   * ในส่วน **Branch** เลือก `main` และโฟลเดอร์ `/(root)` จากนั้นกด **Save**
   * เข้าใช้งานผ่านลิงก์ `https://<username>.github.io/<repository-name>/`
